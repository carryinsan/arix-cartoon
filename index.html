QUICK GUIDE

Welcome to ArixCartoon

1. Write your idea. Generate a storyboard with Gemini Flash. Every scene becomes an editable animation instruction.

2. Direct the film. Edit scene actions, duration, character consistency, and visual style.

3. Add voice. Generate Gemini speech, then request word-level timestamps from the transcription endpoint when available.

4. Export. Record the animated canvas with audio using your browser's MediaRecorder. WebM is the usual browser-supported format; MP4 appears only when your browser supports it.

This is a browser-based 2D cartoon studio, not a neural video generator. Advanced 3D animation, perfect phoneme alignment, frame-accurate MP4 encoding, and cloud project sync are not included in this build.
